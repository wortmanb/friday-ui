# V1 Archive

This directory contains examples and code from the deprecated v1 cat avatar approach.
These are preserved for reference but should not be used in v2 development.

## Fragmented Repos (cleaned up):
- friday-ui-sse-bridge - SSE real-time updates
- friday-ui-mobile-layout - Mobile responsive design
- friday-ui-particle-colors - State-based particle effects  
- friday-ui-favicon - Dynamic favicon system
- friday-ui-smooth-transitions - CSS transition improvements
- friday-ui-activity-log - Debug overlay system
- friday-ui-websocket - WebSocket integration

These were all created as separate repos (anti-pattern) instead of proper feature branches.
